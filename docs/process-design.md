# 当前流程与文档设计（内部）

本文件供 GHShip 维护者使用，不随 CLI 或 npm 分发。仓库根 AGENTS.md 持久记录开发与发布边界。

## 目标与职责

减少重复状态、操作分支和 AI 阅读成本。Issue 是任务入口，不替代 PR、Review 或 CI 的原生事实。

| 记录 | 所在位置 |
|---|---|
| 目标、验收标准、归属、父子、依赖与阻塞决策 | Issue 及原生关系 |
| 实现与作者验证说明 | PR |
| 独立结论与返修意见 | PR Review；没有 PR 的任务在 Issue 留独立结论 |
| 自动测试及运行输出 | CI |
| 产品验收与交付入口 | 父 Issue；无父任务则原 Issue |
| 测试计划、脚本、覆盖关系、固定版本报告 | 仓库测试资产或约定产物 |

只补充缺失信息，引用已有运行和评审。允许固定版本结果矩阵和报告，但它们不承担当前任务状态。验收依据按对象选择：自动测试引用运行；人工测试说明版本、环境、方法、实际结果及覆盖范围；平台治理回读配置或拒绝行为。只有结论依赖且他人需要复核的外部材料才提供约定可访问入口，不强制额外上传完整日志。

## 完成与恢复

涉及仓库文件的切片经相关测试、独立验收、原生审批和门禁合并后由平台关单。无仓库变更的研究、配置和人工验证任务不制造空 PR；按 Issue 标准执行，需要独立验收时由另一执行者在 Issue 记录结论后关闭。独立角色和权限要求仍受项目规则约束，不能因没有 PR 而自批或绕过。

恢复读取 Issue、关联 PR/Review/CI 和当前 Git 成果；各事实按其原生职责核实。不要用本地快照替代最新平台查询。产品验收与切片完成分开，父任务依据实际交付目标结束；本地清理不决定关单时机。

## 内容与分发

| 内容 | 仓库位置 | 分发方式 |
|---|---|---|
| 维护约束 | AGENTS.md | 仅源码仓库 |
| 顶层设计与内部取舍 | docs/ | 仅源码仓库 |
| 人类教程 | README.md | 项目首页 |
| AI 入口 | SKILL.md | CLI 内嵌、安装到 home |
| 公共操作、流水线、配置和命令契约 | references/workflow.md、pipeline.md、setup.md、cli.md | 明确嵌入并随 skill 安装 |
| npm 安装说明 | npm/README.md | npm 包 |
| 测试运行、独立验收及发布变化 | CI、Review、Release | 平台原生记录 |

公共文件只描述当前产品；历史清理、设计争论、内部测试进展不进入这些文件。公开版本仍如实注明依赖、限制和渠道可用性。源码中的产品版本、npm 元数据和 skill 元数据一致，内部文档不通过版本后缀或复制 skill 建立另一套产品行为。

## 验证与交付

检查公共入口链接有效且责任不冲突；对照代码核对命令和限制；包不含内部文件；在隔离 home 安装后逐文件核对 skill；真实更新卸载及六平台 CI、独立评审后经原生门禁交付。已有文档、计划和编译测试不足以宣称用户获得新行为。
